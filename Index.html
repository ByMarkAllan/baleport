Connect Mapbox to Baleport.

Baleport needs a Mapbox public access token for the map, address search, route optimization, and Directions API calls.

Create or copy a Mapbox public access token from your Mapbox account.
In Apps Script, open Project Settings → Script properties.
Add this property, then redeploy or reload the web app:
MAPBOX_PUBLIC_TOKEN = pk.your_mapbox_public_token

For production, apply appropriate Mapbox token restrictions after confirming the final deployed Apps Script origin works with your configuration.
